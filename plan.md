# RusLearn — Имба-сайт по русскому языку

## Стек
- **Backend**: Python + Django (REST API, JWT auth, БД)
- **Frontend**: React + Vite (SPA, анимации, красота)
- **БД**: SQLite (для разработки), PostgreSQL (прод)
- **Styling**: TailwindCSS + shadcn/ui

## Разделы

### Для ученика
- Памятки по темам (5-11 класс)
- Интерактивные упражнения (тесты, вставка букв, диктанты)
- Личный прогресс, статистика
- Генератор заданий (выбор темы, сложности, типа)
- Игровые режимы (викторина, тайм-атака)
- Словарь терминов

### Для учителя
- Создание классов и добавление учеников
- Задание домашних заданий из генератора
- Статистика класса, прогресс каждого ученика
- Конструктор тестов
- Экспорт в PDF

### Генератор заданий
Темы:
- Орфография (безударные гласные, приставки, суффиксы)
- Пунктуация (запятые, тире, двоеточие)
- Морфология (части речи)
- Синтаксис
- Лексика

Типы заданий:
- Вставить пропущенные буквы
- Расставить знаки препинания
- Определить часть речи
- Найти ошибку
- Составить предложение по схеме
