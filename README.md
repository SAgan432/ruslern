# 🇷🇺 РусЛёрн — Интерактивная образовательная платформа по русскому языку (5–11 классы и ЕГЭ)

Платформа развёрнута и перенесена в отдельную папку: `A:\ruslearn`

---

## 🚀 Быстрый запуск

1. **Способ 1:** Дважды кликните по файлу `start.bat` в папке `A:\ruslearn`.
2. **Способ 2:** В терминале выполните:
   ```bash
   cd A:\ruslearn
   npm run dev
   ```
3. Откройте в браузере: **http://localhost:3000**

## 🌟 Возможности платформы

1. **🛡️ Тотальный античит и академическая честность (Anti-Cheat 2.0):**
   * Персональный водяной знак с ФИО, ID и временем на всех тестах.
   * Контроль переключения вкладок, ухода из окна и разделения экрана на телефоне.
   * Полная блокировка буфера обмена (запрет Ctrl+C, Ctrl+V, F12, контекстного меню).
   * Журнал нарушений в реальном времени в базе данных SQLite.
   * **🥪 Официальная пауза (1–2 раза за тест на 10 минут)**: можно перекусить или попить воды без штрафов.

2. **⚔️ PVP Онлайн-дуэли 1 на 1:**
   * Сражения по 4-значному PIN-коду до 10 очков.
   * Тренировочные дуэли с ИИ Ломоносовым.
   * Сплит-прогресс-бар в реальном времени.

3. **🧠 Персональный ИИ-диагност западающих тем:**
   * Интерактивная тепловая карта (Критическая зона <65%, Зона внимания 65–80%, Освоено >80%).
   * Кнопка «Сгенерировать работу над ошибками в 1 клик».

4. **🎤 Голосовая диктовка сочинения (Speech-to-Text):**
   * Запись через микрофон смартфона.
   * Кнопка «✨ 7 абзацев ФИПИ» для мгновенного канонического форматирования.
   * Автоматический подсчёт слов и экспертная проверка К1–К12.

5. **📄 Официальные бланки ФИПИ (А4 / PDF):**
   * Бланк ответов № 1 (с QR-кодом, образцами символов, сеткой клеток и блоком замены).
   * Бланк ответов № 2 (линованный лист для сочинения).
   * Ключи и критерии для учителя.

6. **🎨 Смена тем оформления и озвучки:**
   * 4 темы: Киберпанк Неон, OLED Ультра-чёрный, Изумрудная Матрица, Школьная классика.
   * Выбор любого русского голоса диктора, регулировка скорости и тона речи.
   * Звуковые пресеты (8-bit, Аркада, Дзен).

7. **📱 100% мобильная оптимизация:**
   * Нижний App Bar под большой палец.
   * Выдвижное мобильное меню (Bottom Sheet Drawer).
   * Тактильный виброотклик.
